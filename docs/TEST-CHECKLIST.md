# Checklist manual — MVP funcional

- Abrir Dashboard sem erros.
- Navegar entre Dashboard, Tarefas, Conteúdos, Avaliações e Calendário.
- Criar tarefa, marcar como concluída e excluir.
- Criar avaliação com data.
- Criar conteúdo com domínio, revisão e avaliação vinculada.
- Atualizar a página e confirmar persistência local.
- Confirmar que o Radar classifica risco.
- Confirmar que "O que estudar agora?" ordena conteúdos por prioridade.
- Validar layout em tela estreita/mobile.
