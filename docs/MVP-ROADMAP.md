# GTD Acadêmico — Roadmap do MVP

## Etapa 1 — Base funcional
- Dashboard navegável
- Cadastro de tarefas
- Cadastro de conteúdos
- Cadastro de avaliações
- Persistência local no navegador
- Priorização inicial de estudo
- Radar pré-prova inicial

## Etapa 2 — Dados em nuvem
- Banco de dados
- Autenticação
- Sincronização entre dispositivos
- Modelo normalizado para tarefas, conteúdos, avaliações e sessões de estudo

## Etapa 3 — Inteligência acadêmica
- Revisão espaçada automática
- Score de risco acadêmico
- O que estudar agora? com ranking por prazo, domínio, acerto e revisão
- Registro de horas e questões
- Caderno de erros

## Etapa 4 — Módulos especializados
- GTD Médico
- OSCE e habilidades
- Flashcards
- Biblioteca acadêmica
- PWA
- Integração com IA
