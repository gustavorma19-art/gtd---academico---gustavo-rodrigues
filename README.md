# GTD Acadêmico — Gustavo Rodrigues

Sistema acadêmico de organização, desempenho e preparação baseado no método GTD de David Allen.

## Visão do produto

O GTD Acadêmico organiza compromissos, tarefas, conteúdos, revisões, avaliações, erros, desempenho e módulos especializados como GTD Médico.

## MVP atual

- Dashboard acadêmico
- O que estudar agora?
- Calendário
- Tarefas em fluxo GTD
- Conteúdos e revisões
- Caderno de erros
- Radar pré-prova
- Desempenho
- GTD Médico
- Biblioteca Acadêmica
- Semana Acadêmica
- Central de prompts

## Autoria

Criado e desenvolvido por Gustavo Rodrigues.

> O método GTD (Getting Things Done) foi criado por David Allen. Este projeto é uma aplicação acadêmica autoral inspirada nesse método.
